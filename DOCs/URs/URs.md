# Requisitos de Usuario (URs) - TaskSync Pro

## 1. Gestión de Cuenta
- **UR-01:** El usuario debe poder registrarse proporcionando nombre, apellidos, correo electrónico y contraseña.
- **UR-02:** El usuario debe poder iniciar sesión con su correo electrónico y contraseña.
- **UR-03:** El usuario debe poder actualizar su nombre, apellidos y correo electrónico.
- **UR-04:** El usuario debe poder eliminar su cuenta y todos sus datos asociados.

## 2. Gestión de Tareas
- **UR-05:** El usuario debe poder crear una tarea con al menos un título y una fecha.
- **UR-06:** El usuario debe poder ver una lista de todas sus tareas.
- **UR-07:** El usuario debe poder ver los detalles de una tarea específica.
- **UR-08:** El usuario debe poder editar el título, descripción, fecha y categoría de una tarea.
- **UR-09:** El usuario debe poder eliminar una tarea.
- **UR-10:** El usuario debe poder marcar una tarea como completada o pendiente.

## 3. Organización
- **UR-11:** El usuario debe poder asignar una categoría a una tarea.
- **UR-12:** El usuario debe poder ver todas las categorías disponibles.
- **UR-13:** El usuario debe poder establecer una recurrencia a una tarea (diario, semanal, mensual, horario).
- **UR-14:** El usuario debe poder ver las recurrencias asociadas a sus tareas.

## 4. Recordatorios y Notificaciones
- **UR-15:** El usuario debe recibir notificaciones en tiempo real cuando una tarea esté vencida.
- **UR-16:** El usuario debe recibir notificaciones automáticas en todos sus dispositivos conectados.
- **UR-17:** El usuario debe ver el estado de notificación de sus tareas (pendiente/completada).

## 5. Dashboard y Visualización
- **UR-18:** El usuario debe poder ver un dashboard con el conteo de tareas pendientes y completadas.
- **UR-19:** El usuario debe poder ver una lista de tareas pendientes.
- **UR-20:** El usuario debe poder ver una lista de tareas completadas.

## 6. Sincronización
- **UR-21:** El usuario debe ver los cambios en sus tareas reflejados en tiempo real en todos sus dispositivos.
- **UR-22:** El usuario debe recibir notificaciones de recordatorios en todos sus dispositivos simultáneamente.

## 7. Experiencia de Usuario
- **UR-23:** La interfaz de la API debe devolver respuestas claras y mensajes de error comprensibles.
- **UR-24:** El sistema debe ser rápido y responsive.
